# Figma Community listing — copy to paste

## Plugin name
HTML to Figma

## Tagline (shows in search)
Paste HTML or a URL and get editable Figma layers. On-device.

## Description
Turn HTML into **editable** Figma layers — not a screenshot.

**Two ways in:**
• **Paste HTML** — drop in any markup and convert it instantly.
• **From URL** — enter a page URL and import its HTML.

Each element becomes a real Figma layer, positioned from its on-page box, with:
• frames + text (font size, weight, color, alignment)
• fills, borders, corner radius, opacity
• drop shadows (from box-shadow)
• images (fetched and placed)

Set the viewport width (e.g. 1280) to control how the page lays out before it's
converted.

**Private by design** — the HTML is rendered and parsed inside the plugin. Only
the optional "From URL" mode fetches the page you enter. Free and open source
(MIT): github.com/sinhaankur/figma-plugins
