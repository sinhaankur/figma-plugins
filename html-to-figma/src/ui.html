How to get the bookmarklet
One-time setup — drag this to your browser’s bookmarks bar:
↝ Send to Figma
or copy the bookmarklet code.

Each import
1. Open your page so it fully renders.
2. Click Send to Figma — it copies the layout.
3. Paste here (⌘V), then Import.

Best for simple static pages. For JS-rendered pages (Claude designs, SPAs) use Receive.

Only works for static pages that allow cross-origin fetch. JS-rendered pages won’t render here — use Receive.
